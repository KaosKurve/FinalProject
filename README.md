For this final project, I've created a simple art program that has basic functionality similar to other drawing programs. 
You can draw onto your canvas, select your brush size, erase your drawing with the eraser tool, and use the paint bucket tool to fill in spaces with specific colors. Speaking of color, you could also select up to 8 basic colors: Black, White, Purple, Cyan, Green, Yellow, Blue, and Red.

Something unique about this program is the two standout tools I added, that being the bomb tool and the snake tool. 
Using the bomb tool, you can place down bombs as stamps on your canvas that will light up, after a short amount of time, and blow up in a small explosion of paint in the user's selected color. 
The snake tool allows you to place a 'snake brush' down, and the canvas turns into a little game of snake, where you can use WASD to move the snake in any direction you want. The more you move, the more paint you will leave behind. And just like Snake, if you hit the borders of the canvas or hit the snake's body, the snake tool will deactivate. 
Aside from those unique tools, there is also a color filter button, which allows the user to put their art piece under different photo filters you can scroll through. 
Users can choose up to normal, grayscale, invert, sepia, blue, red, and neon color filters. 
These tools alone allow the user to have fun with their drawings, and allow new opportunities to experiment with their drawings

Other than the tools, there are other basic function buttons that are essential in an art program. 
There is an undo and redo button that can be pressed to undo and redo previous actions; this can also be accessed through keybinds Ctrl + Z and Ctrl + Y. 
The save buttons allow the user to temporarily save their current drawing. Once they close the program, the next time it's opened up, the drawing will be saved. Though the drawing can only be saved once per session, once you open the saved file, it won't be saved again unless you press the save button again.
The clear button is a simple button that will clear all the art you've drawn on your canvas so far. 
The export button allows the user to export their current drawing to be saved in the source folder where the program is located. If a color filter is applied, the image will also export along with the filter.

I'm very happy with what I've created, as it's a simple yet fun art program with lots of simple yet fun tools for the player to play around with. 
If I had more time, I would want to add some more unique tools or 'toys' for the user to mess around with, tools that stand out and won't be found in other programs like my bomb and snake tools. I'd also want to add some additional things like more colors, the ability to add layers, a color picker, and more. More quality of life changes would also be nice, like more keyboard shortcuts for other actions, and the ability to change brush size with a slider rather than with buttons.
